Space Rover Mission Scheduler

Type: University Team Project
Technologies: C++, Custom Data Structures 

Description

A system to schedule and track space rover missions using custom data structures. Missions move between Out, Execution, Back, and Done states according to priority, execution time, and return time to base.

My Role

Implemented mission state transitions using priority queues and stacks

Developed logic to move missions from Out → Exec → Back → Done based on timing rules

Contributed to the design and implementation of custom data structures for mission scheduling

Key Concepts

Priority queues for scheduling and execution order

Stacks for completed missions tracking

Queues for managing mission flow between states

Notes

This was a team project; I was responsible for mission flow logic and data structure implementation

Code demonstrates application of core data structures and algorithms in a practical scenario
