PAWell – Pet Hospital Management System

Type: University Team Project
Technologies: C#, .NET (WinForms), SQL Server

Overview

PAWell is a desktop-based pet hospital management system designed to manage hospital operations including users, pets, staff, and authentication. The system supports role-based access for Admins, Veterinarians, and Customers.

My Contribution

This was a team project. My responsibilities included:

Implementing the Admin profile module, enabling admins to view and update their profiles

Developing functionality to add and manage admins, veterinarians, customers, and animals

Implementing user login and authentication with role-based access

Writing SQL queries (joins, filtering, aggregation) to support data visualizations for hospital revenue and statistics

Key Features

Role-based access control (Admin, Veterinarian, Customer)

Secure user authentication

Admin management of users and animal records

Database-backed operations using SQL Server

Notes

Database design and application development were completed collaboratively as part of the team.
